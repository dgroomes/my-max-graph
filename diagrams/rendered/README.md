# Generated diagram renders

Every SVG in this directory is generated from the same-named maxGraph XML file
one directory up by `my-max-graph render` and checked in so repository
documentation stays sharp and reviewable. The command also writes a PNG for
local visual inspection; those PNGs are intentionally ignored by Git.

Do not hand-edit these files. The original hand-authored design targets live in
[`../reference-svg/`](../reference-svg/).
